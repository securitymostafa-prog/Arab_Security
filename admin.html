تحديث واستخراج ملفات الكود الأساسية للموقع

الكود هو المصدر الأساسي دائماً

كل تعديل تقوم به في لوحة الأدمن (إضافة كورس، تعديل أداة، تغيير كلمة سر أو نصوص) يتم تجهيزه تلقائياً ليكون في ملفات الكود البرمجي الأساسية للمنصة، حتى يقرأ الموقع المنشور على GitHub Pages من الكود مباشرة ويظهر لكل الزوار في العالم بنسبة 100%!

ملف قاعدة بيانات الموقع: js/default-data.js

يحتوي على كافة الكورسات، الأدوات، إعدادات المظهر، والنصوص بعد آخر تعديل قمت به في لوحة الأدمن.

ملف إعدادات الأدمن: js/admin-config.js

يحتوي على اسم المستخدم وكلمة المرور الحالية للأدمن لتعمل في الكود وعلى الموقع في نفس الوقت.

كيفية تحديث الموقع بعد التعديل في خطوتين:
  • الخيار الأول (بسيط ومباشر): اضغط على "تحميل ملف default-data.js" وانقله إلى مجلد js داخل مشروعك على جهازك وارفع المشروع على GitHub، وسيقرأ منه الموقع فوراً.
  • الخيار الثاني (تلقائي بنقرة واحدة): من تبويب "نشر أونلاين على GitHub Pages" اضغط "نشر التعديلات أونلاين" وسيقوم بتحديث الملفين في مستودع GitHub تلقائياً بدون تحميل أي ملفات!

النشر والتحديث المباشر على GitHub Pages

غير متصل بحساب GitHub بعد

يتيح لك هذا القسم ربط لوحة الأدمن بمستودعك على GitHub مباشرة. بمجرد إدخال البيانات لمرة واحدة فقط، يمكنك تعديل أي كورس، أداة، أو كلمة سر من داخل الموقع والضغط على زر "نشر التعديلات أونلاين"، ليتم تحديث الموقع فوراً على GitHub Pages وتظهر التعديلات لكافة الزوار في العالم بدون لمس أي كود!

كيفية إنشاء رمز الوصول (GitHub Token) في 30 ثانية مجاناً:

فتح صفحة إنشاء التوكن في GitHub
  1. افتح الرابط أعلاه (سجل دخولك بحساب GitHub إن طُلب منك).
  2. في خانة Note اكتب: arabsecurity واضبط Expiration على ما تفضله (مثلاً No expiration أو 90 days).
  3. ضع علامة صح (✓) أمام خيار repo (Full control of private repositories).
  4. انزل لأسفل الصفحة واضغط الزر الأخضر Generate token.
  5. انسخ الرمز الذي يظهر لك (يبدأ عادة بـ ghp_...) وضعه في خانة رمز الوصول (Token) أدناه ثم اضغط حفظ!

الربط بقاعدة بيانات Google Firebase

يعمل محلياً (غير مربوط بالسحابة بعد)

ربط الموقع بـ Google Firebase (مجاناً 100%) يجعل أي تعديل أو إضافة تقوم بها من صفحة الأدمن تذهب مباشرة إلى سيرفرات جوجل السحابية، وتظهر فوراً لجميع الناس والزوار في العالم بدون الحاجة لإعادة رفع أي ملفات!

خطوات الحصول على كود الربط المجاني (في دقيقتين):

  1. ادخل إلى موقع console.firebase.google.com وسجل بحساب جوجل.
  2. اضغط على Create a project واكتب اسم المشروع (مثلاً: arabsecurity).
  3. اضغط على علامة الويب </> واضغط Register app.
  4. انسخ كود const firebaseConfig = { ... } والصقه في المربع أدناه!
  5. من القائمة الجانبية في فايربيس اضغط Firestore Database ثم Create database واضغط التالي في وضع (Start in test mode).
